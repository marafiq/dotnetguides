# Impulse v2 - Corrected Architecture

## Key Insight: Embedded TypeScript

Source generators can ONLY emit C# files. But C# files can contain embedded TypeScript in comments. MSBuild extracts it.

```
┌─────────────────────────────────────────────────────────────────────┐
│                    SOURCE GENERATOR (Roslyn)                         │
│                    Emits .g.cs files ONLY                           │
└─────────────────────────────────────────────────────────────────────┘
                                │
                ┌───────────────┼───────────────┐
                ▼               ▼               ▼
        ┌─────────────┐ ┌─────────────┐ ┌─────────────────────┐
        │ Routes.g.cs │ │Handlers.g.cs│ │ TypeScript.g.cs     │
        │ (pure C#)   │ │ (pure C#)   │ │ /* embedded TS */   │
        └─────────────┘ └─────────────┘ └─────────────────────┘
                                                │
                                                ▼
                              ┌─────────────────────────────────┐
                              │    MSBUILD TASK (simple)        │
                              │    Extract /* TS */ comments    │
                              │    Write to ClientApp/generated │
                              └─────────────────────────────────┘
                                                │
                        ┌───────────┬───────────┼───────────┬───────────┐
                        ▼           ▼           ▼           ▼           ▼
                   types.ts   routes.tsx    zod.ts     forms.ts   routeTree.ts
```

## Generated C# File with Embedded TypeScript

```csharp
// TypeScript.g.cs (generated by Roslyn Source Generator)
namespace MyApp.Generated;

/// <summary>
/// Embedded TypeScript for client-side code generation.
/// MSBuild task extracts content between markers.
/// </summary>
public static partial class TypeScriptOutput
{
    public const string Types = """
    /* IMPULSE:types.ts */
    export interface ResidentSummary {
      id: number;
      name: string;
    }

    export interface ResidentDetailProps {
      resident: ResidentSummary;
      createdAt: string;
    }
    /* END:types.ts */
    """;

    public const string Validation = """
    /* IMPULSE:validation/createResident.ts */
    import { z } from 'zod';

    export const createResidentSchema = z.object({
      name: z.string().min(1).max(100),
      email: z.string().min(1).email(),
    });
    /* END:validation/createResident.ts */
    """;

    public const string Routes = """
    /* IMPULSE:routes/residents/$id.tsx */
    import { createFileRoute } from '@tanstack/react-router'
    import type { ResidentDetailProps } from '../types'

    export const Route = createFileRoute('/residents/$id')({
      loader: async ({ params }) => {
        const res = await fetch(`/api/residents/${params.id}`)
        return res.json() as Promise<ResidentDetailProps>
      },
      component: () => import('@features/Residents/Detail'),
    })
    /* END:routes/residents/$id.tsx */
    """;

    public const string Forms = """
    /* IMPULSE:forms/useCreateResident.ts */
    import { useImpulseForm } from '@impulse/react'
    import { createResidentSchema } from '../validation/createResident'

    export function useCreateResident() {
      return useImpulseForm({
        schema: createResidentSchema,
        endpoint: '/api/residents',
        method: 'POST',
      })
    }
    /* END:forms/useCreateResident.ts */
    """;
}
```

## MSBuild Task: Simple Text Extraction

```csharp
// ImpulseExtractTask.cs
public class ImpulseExtractTask : Task
{
    [Required]
    public string SourceFile { get; set; }  // TypeScript.g.cs

    [Required]
    public string OutputDir { get; set; }   // ClientApp/generated

    public override bool Execute()
    {
        var content = File.ReadAllText(SourceFile);
        var regex = new Regex(@"/\* IMPULSE:(.+?) \*/(.+?)/\* END:\1 \*/",
            RegexOptions.Singleline);

        foreach (Match match in regex.Matches(content))
        {
            var filePath = match.Groups[1].Value;  // "types.ts"
            var tsCode = match.Groups[2].Value;    // TypeScript content

            var fullPath = Path.Combine(OutputDir, filePath);
            Directory.CreateDirectory(Path.GetDirectoryName(fullPath));
            File.WriteAllText(fullPath, tsCode.Trim());
        }

        return true;
    }
}
```

## Why This Is Better

| Before (model.json) | After (embedded TS) |
|---------------------|---------------------|
| Two serialization formats | Single .cs file |
| Model travels between processes | No cross-process data |
| Complex MSBuild task | Simple regex extraction |
| Timing issues with model.json | Generated at compile time |
| Hard to debug | TypeScript visible in .cs |

## Simplified Flow

```
Developer Code
      │
      ▼
┌─────────────┐
│   Roslyn    │──▶ Routes.g.cs (pure C#)
│   Source    │──▶ Handlers.g.cs (pure C#)
│   Generator │──▶ TypeScript.g.cs (C# with embedded TS)
└─────────────┘
      │
      │ (all happen at compile time)
      ▼
┌─────────────┐
│  MSBuild    │──▶ Extract /* IMPULSE:path */ ... /* END:path */
│  Extract    │──▶ Write to ClientApp/generated/
│  Task       │
└─────────────┘
      │
      ▼
┌─────────────┐
│  Vite/Bun   │──▶ Bundle for dev/prod
└─────────────┘
```
