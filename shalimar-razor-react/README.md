# Shalimar Razor-React Compiler

> **Write React in C# using Razor syntax. Zero TypeScript authoring.**

```
.razor → RazorProjectEngine → SyntaxTree → TSX Emitter → React Components
```

## The Proof

Microsoft's `Microsoft.AspNetCore.Razor.Language` package provides a battle-tested Razor parser with 615M+ NuGet downloads. We leverage this parser and write only the TSX emitter.

**Lines of code Microsoft wrote:** ~50,000+ (parser alone)
**Lines of code we write:** ~500 (emitter)

## Quick Demo

### Input: `ResidentCard.razor`

```razor
@inherits SliceComponent<ResidentCardProps>

<div class="card resident-card">
    <h1>@Props.Name</h1>

    @if (Props.IsHighRisk)
    {
        <div class="alert">High Fall Risk</div>
    }

    @foreach (var med in Props.Medications)
    {
        <MedRow medication="@med" />
    }

    <button @onclick="@OnViewDetails">View Details</button>
</div>
```

### Output: `ResidentCard.tsx`

```tsx
// Generated by Shalimar.Razor - DO NOT EDIT
import React from 'react';
import { MedRow } from './MedRow';

export interface ResidentCardProps {
  // TODO: Extract props from usage
}

export function ResidentCard(props: ResidentCardProps) {
  return (
    <div className="card resident-card">
      <h1>{props.Name}</h1>

      {props.IsHighRisk && (
        <div className="alert">High Fall Risk</div>
      )}

      {props.Medications.map((med) => (
        <MedRow medication={med} />
      ))}

      <button onClick={OnViewDetails}>View Details</button>
    </div>
  );
}
```

## Transformations

| Razor | TSX | Notes |
|-------|-----|-------|
| `class="x"` | `className="x"` | JSX requirement |
| `for="x"` | `htmlFor="x"` | JSX requirement |
| `@Props.Name` | `{props.Name}` | Expression binding |
| `@if (c) { }` | `{c && ( )}` | Conditional render |
| `@foreach (x in xs)` | `{xs.map(x => ())}` | List rendering |
| `@onclick="@H"` | `onClick={H}` | Event handlers |

## Usage

```bash
# Build
dotnet build

# Run tests
dotnet test

# Compile a Razor file
dotnet run --project src/Shalimar.Razor.Cli -- compile samples/Components/ResidentCard.razor

# Dump syntax tree (debugging)
dotnet run --project src/Shalimar.Razor.Cli -- tree samples/Components/ResidentCard.razor

# Run demo
dotnet run --project src/Shalimar.Razor.Cli -- demo
```

## Why This Works

1. **Microsoft maintains the parser** - 10+ years of hardening, edge case handling, and IDE integration
2. **We just write the emitter** - ~500 lines to transform AST nodes to TSX
3. **Familiar syntax** - .NET developers already know Razor
4. **Type safety** - TypeScript interfaces from C# types
5. **No runtime dependency** - Output is pure React, runs anywhere
